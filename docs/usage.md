# Applet.Watch.at365 機能・操作・設定

Watch.at365のデスクトップ時計を、AppDock.at365用のAppletとして切り出したものです。C# / WPF製で、半透明、時分・秒・日付の見た目を引き継ぎ、フォントは利用するWindowsにインストール済みのものを参照します。クリックを透過し、フォーカスを奪わない時計専用ウィンドウとして表示します。

## フォント

フォントは同梱しません。設定の「フォント」で名前を入力するか、「フォントを選ぶ」でWindowsのフォント選択を開きます。OKでフォント名を即時保存・反映し、キャンセルでは変更しません。文字サイズ・透明度などは既存の設定を使います。

既定は空欄で、この場合はSegoe UIで表示します。選択したフォントが端末にない場合も通知せずSegoe UIで表示し、保存済みのフォント名は保持します。新しくフォントをインストールした場合はWatchを再起動してください。

## 動作環境

Windows x64とAppDock.at365 **v0.36.8以降**が必要です。現行のAppDockでも利用できます。

## 導入・更新

1. AppDockをトレイの「終了」から完全終了します。
2. `A:/40.ARTIFACT/Applet.Watch.at365/Applet.Watch.at365/` を、AppDock.at365.exeの隣の `extensions/Applet.Watch.at365/` に配置します。
3. AppDockを起動し、「Applet」一覧で **Applet.Watch.at365** を有効にします。

更新時も配布物一式を置き換えてください。AppDockの`settings.json`に保存済みの設定は維持されます。

```text
任意の配置先/
├─ AppDock.at365.exe
├─ settings.json
└─ extensions/
   └─ Applet.Watch.at365/
      ├─ extension.json
      └─ Applet.Watch.at365.exe
```

## 使い方と設定

「Applet → Watch.at365 → 設定」で、表示状態・モニター・上端／下端・左右／上下の余白・文字サイズ・不透明度・秒／日付表示を編集して保存します。変更は再起動せずに反映されます。

モニター未接続時はメインモニターへ退避し、選択は保存したまま保持します。余白と文字サイズはDIPで扱い、DPIに合わせて描画します。画面からはみ出す場合は時計を画面内に収めます。

時計はAppDock終了・Applet無効化・再起動時に閉じます。AppletはAppDockが起動・管理する専用EXEで、直接起動する独立した設定画面はありません。

## コマンド

| 表示名 | コマンドID |
| --- | --- |
| 時計を表示 | `at365.watch.settings.visible.on` |
| 時計を非表示 | `at365.watch.settings.visible.off` |
| 時計の表示を切り替え | `at365.watch.settings.visible.toggle` |

Ctrl+PのコマンドパレットとApplet画面のボタンから実行できます。新規導入時に`at365.watch.settings.visible.toggle`へグローバルPauseを割り当てます。キーと条件は「設定 → ショートカット」から変更できます。

## AppDockからの更新

「設定 → バージョン情報・更新」の一括更新、またはこのAppletの個別更新ボタンを利用できます。配布元が`update.json`と`update.zip`を提供している場合に対応します。更新元は「インストール済みのApplet」の「更新元の設定」で変更し、保存してください。ローカルフォルダー・UNC・HTTP(S)・GitHub Releaseに対応し、「既定に戻す」も利用できます。

更新内容を確認して再起動すると配布ファイル一式を交換します。AppDock側の設定・有効状態・保存データは保持します。詳細は[AppDockの更新操作](../../AppDock.at365/docs/usage.md#アップデート)を参照してください。

開発・ビルドについては[開発ガイド](../DEVELOPMENT.md)を参照してください。

## Codexからの設定変更

時計の表示・上端/下端・左右/上下の余白・文字サイズ・不透明度・秒/日付表示をCodexから取得・変更できます。表示/秒/日付にはON/OFF/切り替えコマンドもあり、ショートカットへ割り当てられます。接続中モニターの選択はAppDockの設定画面から行ってください。

## 共通の設定画面

AppDockの「設定」またはApplet詳細の「設定」タブで、時計の表示・表示位置・文字と透明度のカードから編集できます。本体と同じテーマ・入力欄・自動保存を使い、起動待ちは末尾の共通カードにあり、ページを持つAppletでは表示方法も設定できます。既存の設定値・コマンドIDは引き継ぎます。
