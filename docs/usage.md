# Applet.Watch.at365 機能・操作・設定

半透明の時計と日付をデスクトップに表示するAppletです。時計と日付は別々に表示・配置でき、クリックを透過してフォーカスを奪いません。フォントはWindowsにインストール済みのものを使用します。

## フォント

フォントは同梱しません。「共通の見た目」の「フォント」で名前を入力するか、同じ枠内の「フォントを選ぶ」でWindowsのフォント選択を開きます。ボタンは入力欄の下に置かれ、ライトテーマでは灰色になります。OKでフォント名を即時保存・反映し、キャンセルでは変更しません。フォントと不透明度は時計・日付に共通です。文字サイズは時計・秒・日付それぞれの設定を使います。

既定は空欄で、この場合はSegoe UIで表示します。選択したフォントが端末にない場合も通知せずSegoe UIで表示し、保存済みのフォント名は保持します。新しくフォントをインストールした場合はWatchを再起動してください。

## 動作環境

Windows x64とAppDock.at365 **v0.105.8以降**が必要です。

## 導入・更新

1. AppDockをトレイの「終了」から完全終了します。
2. `A:/40.ARTIFACT/Applet.Watch.at365/Applet.Watch.at365/` を、AppDock.at365.exeの隣の `extensions/Applet.Watch.at365/` に配置します。
3. AppDockを起動し、「Applet」一覧で **Applet.Watch.at365** を有効にします。

更新時も配布物一式を置き換えてください。AppDockの`settings.json`に保存済みの設定は維持されます。

```text
任意の配置先/
├─ AppDock.at365.exe
├─ settings.json
└─ extensions/
   └─ Applet.Watch.at365/
      ├─ extension.json
      └─ Applet.Watch.at365.exe
```

## 使い方と設定

AppDockの設定でWatchを選び、次の項目を編集します。変更は確定時に保存され、再起動せずに反映されます。

| グループ | 設定と既定値 |
| --- | --- |
| 共通の見た目 | フォントは空欄（Segoe UI）、不透明度0.4、フォント選択ボタン |
| 時計の表示 | 時計を表示OFF、秒を表示ON、時計の文字サイズ420、秒の文字サイズ210 |
| 時計の表示位置 | メインモニター（自動）、左上、左右の余白20、上下の余白0 |
| 日付の表示 | 日付を表示OFF、フォーマットは月/日と英語の曜日（例: 10/30 Fri）、文字サイズ210 |
| 日付の表示位置 | メインモニター（自動）、右上、左右の余白20、上下の余白0 |

時計をOFFにしても日付をONにできます。両方OFFでは表示ウィンドウを隠し、表示更新のタイマーを停止します。保存済みの明示的なON/OFFは維持し、省略した表示項目は既定OFFになります。

表示位置は左上・中央上・右上・左下・中央下・右下から選べます。時計と日付は別のモニターにも置けます。同じ位置に置くと重なるため、位置や余白で調整してください。秒は時・分の隣に表示し、サイズを独立して指定できます。

日付は英語の曜日付き月日、スラッシュまたはハイフン区切りの年月日、日本語の月日・曜日付き月日・曜日付き年月日から選べます。選択肢には表示例を添えています。

モニター未接続時は対象の表示だけメインモニターへ退避し、選択は保存したまま保持します。余白と文字サイズはDIPで扱い、DPIに合わせて描画します。横幅が足りない場合、時計は時・分と秒を同じ比率で縮小し、日付は独立して縮小します。

時計はAppDock終了・Applet無効化・再起動時に閉じます。AppletはAppDockが起動・管理する専用EXEで、直接起動する独立した設定画面はありません。

## コマンド

| 表示名 | コマンドID |
| --- | --- |
| 時計を表示 | `at365.watch.settings.visible.on` |
| 時計を非表示 | `at365.watch.settings.visible.off` |
| 時計の表示を切り替え | `at365.watch.settings.visible.toggle` |
| 日付を表示 | `at365.watch.settings.showDate.on` |
| 日付を非表示 | `at365.watch.settings.showDate.off` |
| 日付の表示を切り替え | `at365.watch.settings.showDate.toggle` |

コマンドパレットやコマンドトリガーから実行できます。新規導入時に`at365.watch.settings.visible.toggle`へグローバルPauseを割り当てます。この操作は時計だけを切り替えます。キーと条件は「設定 → コマンドトリガー」から変更できます。

「時計を表示」「日付を表示」の説明には、それぞれの表示切り替えコマンドへのリンクがあります。リンクを押すと対象を選択したコマンドパレットが開き、そこで実行できます。リンクを開くだけでは表示状態を変更しません。

## AppDockからの更新

「設定 → バージョン情報・更新」の一括更新、またはこのAppletの個別更新ボタンを利用できます。配布元が`update.json`と`update.zip`を提供している場合に対応します。更新元は「インストール済みのApplet」の「更新元の設定」で変更し、保存してください。ローカルフォルダー・UNC・HTTP(S)・GitHub Releaseに対応し、「既定に戻す」も利用できます。

更新内容を確認して再起動すると配布ファイル一式を交換します。AppDock側の設定・有効状態・保存データは保持します。詳細は[AppDockの更新操作](../../AppDock.at365/docs/usage.md#アップデート)を参照してください。

開発・ビルドについては[開発ガイド](../DEVELOPMENT.md)を参照してください。

## Codexからの設定変更

時計と日付の表示・位置・左右/上下の余白、時計/秒/日付の文字サイズ、日付フォーマット、フォント、不透明度、秒の表示をCodexから取得・変更できます。時計/秒/日付の表示にはON/OFF/切り替えコマンドもあり、ショートカットへ割り当てられます。接続中モニターの選択はAppDockの設定画面から行ってください。

## 共通の設定画面

本体と同じテーマ・入力欄・自動保存を使います。フォント選択は「共通の見た目」、時計と日付の設定はそれぞれ隣接する表示・表示位置のグループへまとめています。起動待ちは末尾の共通設定で指定できます。
